# ⏰ Working Time! - Desktop Pomodoro Widget

Hello! This is **Working Time!**, a compact, minimalist desktop Pomodoro timer. 

I built this because I wanted a distraction-free focus tool that sits cleanly on my desktop without needing a web browser open. It is built using **React** for the user interface, **TypeScript** for reliable code quality, and **Electron** to package it into a native desktop window.

---

## 🛠️ The Tech Stack

- **Frontend:** React (TypeScript)
- **Desktop Runtime:** Electron
- **Styling:** Custom CSS3

---
